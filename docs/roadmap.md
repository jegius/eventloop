# План реализации (Roadmap)

Дорожная карта разбита на этапы. Каждый этап завершается работающим, проверяемым
результатом.

- [x] Создать структуру монорепо.
- [x] Написать README, архитектуру, правила.
- [x] Настроить Rust-проект (`interpreter/`) с компиляцией в WASM.
- [x] Настроить фронтенд (Vite + TypeScript + Web Components).
- [x] Настроить связку фронтенд ↔ WASM.

## Этап 1: Базовый интерпретатор (Rust) ✅

- [x] Лексер: токенизация чисел, строк, идентификаторов, операторов, ключевых слов.
- [x] Парсер: recursive descent, построение AST.
- [x] Интерпретатор: tree-walking.
- [x] Значения: `undefined`, `null`, `boolean`, `number`, `string`, `object`, `array`, `function`.
- [x] Окружения и замыкания.
- [x] Управляющие конструкции: `if/else`, `for`, `while`, `switch`, `break`, `continue`.
- [x] Функции: объявления, выражения, стрелочные, `this`.
- [x] Объекты и массивы: литералы, доступ к свойствам, методы.
- [x] Консоль вывода.

**Критерий готовности**: интерпретатор выполняет простые программы и выводит результат.
